# Машинное обучение на графах

Учебные работы по курсу «Машинное обучение на графах».

| Папка | Содержание |
|---|---|
| `Практика 1` | Графовые сети 2: решение заданий по NetworkX |
| `Практика 2` | Построение графа, расчёт характеристик, интерактивная визуализация (PyVis, vis.js) на датасетах Dolphins и Les Misérables |
| `Практика 3` | Граф социальной сети ВК, предсказание связей с помощью GNN, метрики |
| `Практика 4` | Персональный roadmap инженера: гетерогенный граф «человек–навык–проект» на данных вакансий, HeteroGNN |
| `Практика 5` | Реализация алгоритма PageRank |
| `КР` | Контрольная работа: сеть объектов капитального строительства — анализ структуры, модели Барабаши–Альберт и Уоттса–Строгаца, сообщества (Girvan–Newman, Louvain), классификация узлов, прогнозирование связей и регрессия на узлах; презентация |

Также в корне: перечень задач и ответы на вопросы к зачёту.

**Стек:** Python, NetworkX, PyTorch Geometric, PyVis, pandas, matplotlib.
